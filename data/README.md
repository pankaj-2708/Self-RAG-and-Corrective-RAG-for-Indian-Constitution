# data

All raw corpus files, vector stores, and evaluation artifacts used by the pipeline.

> [!NOTE]
> Many files in this directory are **not committed to git** (see `.gitignore`). The table below marks each item's tracking status clearly.

## Files & Directories

| Path | Tracked | Description |
|---|---|---|
| `articles.json` | ✅ Git | All articles of the Constitution of India, scraped from the [Legislative Department](https://legislative.gov.in/constitution-of-india/). Keys are article titles, values are article text. |
| `penal_code_sections.json` | ✅ Git | Sections of the Indian Penal Code (IPC), sourced from [India Code](https://www.indiacode.nic.in/). Keys are section titles, values are section text. |
| `demo_sc.png` | ✅ Git | CLI demo screenshot (used in the root README). |
| `optimal_k_inertia.png` | ✅ Git | Elbow / silhouette plot used to select the optimal K for clustering. |
| `constitution_and_ipc.chroma/` | ❌ Gitignored | Persisted [ChromaDB](https://www.trychroma.com/) vector store. Generated by `src/create_vector_store.py`. |
| `constitution_and_ipc.faiss/` | ❌ Gitignored | FAISS index (experimental alternate vector store). |
| `knowledge_graph.json` | ❌ Gitignored | Ragas knowledge graph built over the full corpus (entity + relationship structure). Generated by `src/evaluation/knowledge_graph.py`. |
| `knowledge_graph2.json` | ❌ Gitignored | Alternate knowledge graph build. |
| `test_set.csv` | ❌ Gitignored (`*.csv`) | 50-row synthetic evaluation dataset generated by Ragas `TestsetGenerator`. |
| `sample_test_set.csv` | ❌ Gitignored (`*.csv`) | Smaller sample of the test set used for quick checks. |
| `df.csv` | ❌ Gitignored (`*.csv`) | Full embedded document dataframe used for K-means clustering. |
| `sampled_df.csv` | ❌ Gitignored (`*.csv`) | Stratified sample (100 docs) selected via silhouette-optimal K-means clusters. |
| `sample_results.csv` | ❌ Gitignored (`*.csv`) | Sample evaluation results for inspection. |
| `evaluation_progress_results/` | ❌ Gitignored (`*.csv`) | Versioned, resumable per-query Ragas evaluation outputs. |

## Regenerating Ignored Artifacts

| Artifact | Command |
|---|---|
| ChromaDB vector store | `python src/create_vector_store.py` |
| Knowledge graph | `python src/evaluation/knowledge_graph.py` |
| Clustered docs + test set | `dvc repro` (or run clustering → test set generation scripts in order) |
| Evaluation results | `python src/evaluation/evaluate.py` |

> Raw JSON corpus was scraped and structured via [`notebooks/data_collector.ipynb`](../notebooks/data_collector.ipynb).
